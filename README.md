# RECESS (가칭) — 고등학생 커뮤니티 발표용 데모

학교와 재학 여부가 확인되는 고등학생들이 여러 학교에 걸쳐 일상·학교생활·공부·입시를 이야기하는 커뮤니티의 시연용 웹앱.
서버·API 키 없이 브라우저(localStorage)만으로 작동한다. 학교·프로필·게시글·광고는 모두 예시 데이터다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5180
```

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 (수정하면 바로 반영) |
| `npm run build` | 타입 검사 + 배포용 빌드 → `dist/` |
| `npm run build:artifact` | 한 파일짜리 공유 페이지 → `artifact/recess-demo.html` |
| `npm run typecheck` | 타입 검사만 |

`dist/` 폴더는 정적 호스팅(GitHub Pages, Netlify 등)에 그대로 올릴 수 있다.

## 이름 바꾸기

서비스 이름은 가칭이다. `src/config.ts`의 `BRAND`와 `index.html`의 `<title>`만 바꾸면 화면 전체에 반영된다.

## 60초 시연 순서

발표 직전에 **설정 → 데모 초기화**를 한 번 눌러 두면 처음 상태에서 시작한다.

1. **(0–10초) 통합 피드** — 첫 화면에서 대치·중계·목동 여러 학교 글이 한 피드에 섞여 있는 것을 보여준다. 작성자 옆 `닉네임 · 학교 · 인증 표시`를 짚는다(실명·반·번호 없음).
2. **(10–18초) 필터** — `공부` 탭 → 학교 드롭다운에서 `대치 B고` → 결과가 줄어드는 것 확인 → `필터 초기화`.
3. **(18–32초) 입장·학생 인증 체험** — `글쓰기` → 준비된 예시 프로필 `쉬는시간러` → 예시 학생증 선택 → `이 예시 자료로 인증 체험하기` → 완료 화면의 "완전한 익명 서비스는 아니에요" 문구를 짚고 `계속하기`.
4. **(32–42초) 글쓰기** — 바로 열린 글쓰기 창에 제목·내용 입력 → `올리기` → 피드 맨 위에 강조되어 나타난다.
5. **(42–48초) 반응** — 내 글을 열어 댓글 하나 달기(댓글 수 0→1), 다른 글에 좋아요·저장 눌렀다 끄기.
6. **(48–54초) 선택형 뱃지** — `내 프로필` → `수학 1등급` 스위치 켜기 → 미리보기와 내 글에 뱃지가 붙는다. `시험·과목 보기`로 어떤 시험 기준인지 보여준다.
7. **(54–60초) 수익 모델** — 홈 피드 4번째 글 아래 `광고 · 자체 운영 학원 예시` 카드 → `자세히 보기` → `상담 체험하기`. 연락처 없이 끝나고 "전송되지 않았어요"가 뜬다.

시간이 남으면: 글 `⋯` 메뉴 → 작성자 차단(그 학생 글이 사라짐) → 설정에서 차단 해제.

## 데모로 처리한 부분

- **로그인·회원가입 없음** — 데모 프로필은 이 브라우저에만 저장된다.
- **학생 인증은 연출** — 파일을 받지 않고 예시 학생증/재학증명서 그림으로 흐름만 보여준다. 실제 재학 확인을 하지 않는다.
- **뱃지 기록은 예시** — 체험용 프로필에는 예시 뱃지 5개가 들어 있다. 석차 뱃지·학원 등록/결제로 받는 뱃지는 없다.
- **신고는 기록만** — 운영자에게 전송되지 않고 설정의 '신고 시연 기록'에만 남는다.
- **상담 체험은 전송 없음** — 관심 과목·희망 시간만 고르고 연락처는 받지 않는다.
- **좋아요 수** — 예시 글의 기본값(다른 학생들의 반응) + 이 브라우저의 데모 프로필이 누른 수.
- **목동** — 확장 시나리오를 보여주는 예시 콘텐츠다. 확보된 사용자나 팀 학원이 있다는 뜻이 아니다.
- **저장 범위** — `recess-demo:`로 시작하는 localStorage 키 하나만 쓴다. 데모 초기화는 이 키만 지운다.

## 구조

```
src/
  config.ts            서비스 이름·안내 문구·저장 키
  types.ts             데이터 타입
  data/catalog.ts      카테고리·지역·가상 학교·뱃지·신고 사유
  data/seed.ts         예시 학생 16명·게시글 24개·댓글 50개·광고
  store/state.ts       상태 변경(reducer)·저장·초기화
  store/AppContext.tsx 화면 상태(보기·필터·모달·토스트)와 참여 게이트
  lib/feed.ts          검색·필터·정렬·차단/숨김 반영
  components/          작성자 표시, 게시글 카드, 광고 카드, 메뉴, 모달, 레이아웃
  modals/              입장·인증, 글쓰기, 상세·댓글, 신고, 뱃지, 학원 상세
  views/               홈, 저장한 글, 내 프로필, 설정
  styles.css           색·글꼴 토큰(밝게/어둡게)과 반응형 레이아웃
```
